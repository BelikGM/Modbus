========================================================================
  ДРАЙВЕРЫ ПЕРЕХОДНИКОВ USB → RS-485
========================================================================

Эта папка едет вместе с программой. Положите сюда установщики драйверов —
и на новом компьютере, где переходник не определился сам, всё нужное будет
под рукой, без интернета.

Программа сама ничего отсюда не устанавливает: драйвер ставится обычным
запуском его установщика от имени администратора.


КАК ПОНЯТЬ, КАКОЙ ДРАЙВЕР НУЖЕН
-----------------------------------------------------------------------
1. Воткните переходник в USB.
2. Откройте «Диспетчер устройств» (Win+X → Диспетчер устройств).
3. Если в разделе «Порты (COM и LPT)» появился COM-порт — драйвер уже есть,
   ставить ничего не нужно.
4. Если устройство с жёлтым восклицательным знаком в «Другие устройства» —
   откройте его свойства → «Сведения» → «ИД оборудования» и посмотрите
   код вида VID_XXXX. По нему определяется микросхема:

   VID_10C4  Silicon Labs CP210x   — самый частый в дешёвых переходниках
   VID_0403  FTDI FT232            — в переходниках подороже
   VID_1A86  WCH CH340 / CH341     — очень распространён
   VID_067B  Prolific PL2303
   VID_04D8  Microchip

   Эти же коды программа использует в кнопке «Найти адаптер»: она сама
   определяет, какой из COM-портов — переходник RS-485.


ГДЕ БРАТЬ
-----------------------------------------------------------------------
   Silicon Labs CP210x  silabs.com → Developers → USB to UART Bridge VCP Drivers
   FTDI                 ftdichip.com → Drivers → VCP Drivers
   WCH CH340            wch-ic.com → Downloads → CH341SER
   Prolific PL2303      prolific.com.tw → Support → USB to UART

   Скачайте установщик под свою Windows и положите файл в эту папку.
   Удобно называть по микросхеме, например: CP210x_VCP_Windows.exe


ПОСЛЕ УСТАНОВКИ
-----------------------------------------------------------------------
Переходник появится как обычный COM-порт. В программе:
  «Подключение» → «Найти адаптер» (или выберите порт вручную) →
  укажите скорость (обычно 9600) → «Подключить».

Если параметры связи неизвестны — «Умный автопоиск» на вкладке поиска
устройств переберёт скорости, чётность и число стоп-битов сам.
